# People Risk

## People Risk defined

Vulnerability created when critical institutional knowledge resides in a small number of individuals. When a lead data curator retires without a documented succession plan, or a wave of RIFs eliminates the team that knows how to run a specialized processing chain, the data may still technically exist while becoming operationally inaccessible. That kind of loss is invisible to systems that only track files and metadata.

## Subcategories

### P-1

#### Description

No documented succession plan

No written plan identifies a successor or outlines knowledge transfer steps for critical roles

#### How to find

Search for the number of people in a dataset group and how long it has existed to get an estimate of how many people are available to be a successor. Look for detailed documentation of the how to take the data measurements and process the dataset.

### P-2

#### Description

Key personnel retirement-eligible

One or more people critical to production or QC eligible to retire within 2 years

#### How to find

Search for people in charge of the dataset group and data processing. Search for how QC is done and by who. Look for staffing numbers and mentions of retirements. If find people, find when they started working with the dataset and if they've published papers (get ORCID), what is the earliest year, to get an estimate of their age.

### P-3

#### Description

Critical undocumented knowledge

Processing, calibration, or QC expertise held by individual(s) but not captured in documentation or code

#### How to find

Want to know if a person stops working with the dataset, will another person be able to continue making the dataset. Search to find publically available software, dataset processing documentation, or code to process the dataset and peform QC. Want information on whether there is no documentation on how to process the dataset or there is.

### P-4

#### Description

Single person is point of failure

Loss of one individual would halt production, QC, or distribution

#### How to find

Search for people in charge of the dataset group and data processing. Search for how quality control (QC) is done and by who. Look for staffing numbers and mentions of retirements or layoffs that would impact the dataset from being measured and/or processed.
